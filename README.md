# Let Him Yap

> Why did they silence my boy? LET HIM YAP.

Directly inspired by Casualties: Unknown, Let Him Yap is a highly configurable contextual dialogue system.

Players now dynamically react to pain, danger, exhaustion, drowning, fear, food, and more with floating overhead speech and immersive typewriter-style dialogue.

Designed for immersion-heavy modpacks, survival experiences, roleplay servers, and emergent storytelling.

 

***

# Note

This mod is currently in an open public beta. What you see is very much currently in development. Expect stuff to not always work. Features subject to change.

 

***

# Features

## Dynamic Contextual Dialogue

Players can react to:

*   low health
*   pain and heavy damage
*   drowning
*   hunger
*   fear events, such as nearby lightning strikes and explosions
*   insomnia
*   eating food
*   modded conditions through API integrations

***

## Typewriter Speech System

Dialogue appears gradually character-by-character with:

*   configurable typing speed
*   health-based slowdown
*   adrenaline recovery behavior
*   optional typing sounds
*   interruption handling

***

## Immersive Floating Dialogue

*   overhead speech visible to nearby players
*   first-person HUD thoughts
*   underwater garbling
*   configurable fading
*   configurable rendering positions/scales
*   per-player dialogue colors

***

## Last Words System

Interrupted or unfinished dialogue can become death messages and final thoughts. See the last thing you said right before getting absolutely brutalized by that horde.

***

## Fully Configurable

Uses TOML configs for:

*   dialogue pools
*   conditions
*   weights and priorities
*   rendering
*   colors
*   timing
*   sounds
*   modded compatibility pools

***

## API Support

Addon mods can:

*   register new dialogue pools
*   force contextual dialogue
*   add compatibility integrations
*   define custom reactions dynamically
*   and more things I'm too lazy to state here. I'll make a page all about it later, trust.
